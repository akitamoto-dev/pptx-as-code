# ms-format スキル

技術説明資料の標準書式。**書式（色・フォント・座標）と、文章・構成の規範の両方**を定める。
Microsoft 全社の公式テンプレートではなく、技術説明資料向けに実運用の資料から起こしたもの。

このスキル単体では資料を作れない。生成の仕組みは [../content-to-pptx/SKILL.md](../content-to-pptx/SKILL.md) が持つ。

## 適用する

共通の雛形（プラグイン直下の `template/`）を作業ディレクトリへコピーしたあと、次を実行する。

```bash
bash <このスキル>/apply.sh <作業ディレクトリ>
```

`deck-src/theme.json` が青基調に差し替わり、`assets/icons/` に Fluent アイコンが入る。
見本から始める場合は、表示される案内に従って `samples/sample.js` をコピーする。

## 書式

値の正は [theme.json](theme.json)。定義側で数値を書かず、content-to-pptx のヘルパー経由で使う。

| 区分 | 内容 |
|---|---|
| 色 | 主色 `0078D4`、濃い青 `005A9E`、薄い青 `E8F2FC`、本文 `333333`、補足 `666666` |
| 赤 | `B91C1C`。攻撃の起点・最終的な被害・禁止だけに使う |
| フォント | 日本語は Yu Gothic UI（代替 Meiryo UI → Noto Sans CJK JP）、コードは Consolas |
| 構成 | タイトル → キーメッセージ → ＜見出し＞ → 本文・図・表 → 出典 |
| アイコン | Fluent UI System Icons。`icons/icons.json` に定義があり、足りなければ追記して `uv run tools/fetch_icons.py` で取得する |

## 素材の権利

同梱のアイコンは [Fluent UI System Icons](https://github.com/microsoft/fluentui-system-icons)（Microsoft 製・MIT。取得できる字形と命名がここで分かる）。
別のセットに差し替える場合も同じで、Lucide は ISC、Tabler は MIT、Material Symbols は Apache-2.0（`icons.json` の prefix を変えれば同じ手順で取得できる）。
PowerPoint に組み込まれているアイコンは、文書の中で使う分には契約の範囲だが、単体で抜き出しての再配布・再販ができない。取得の手段にしない。

## 文章と構成の規範

**正本は [writing-rules.md](writing-rules.md)。判断に迷う表現があれば必ず読む。**
書式を守っていても、次の規範を外すとこのフォーマットにならない。

- タイトルは名詞の体言止め。キーメッセージは主語と述語のある完全な文をですます調で書く。それ以外は常体か体言止め
- ＜見出し＞は内容を言い当てる短い名詞句。個数や主張を入れず、直下にそのブロックが何を示すかの一文を置く
- **1 スライド 1 論点。** 論点が増えたら分割し、説明に混ぜる軸も増やさない
- 自己完結。章番号・他スライド・資料自体への言及を書かず、後で初出になる用語を先に使わない
- 下部にまとめ帯やキーメッセージの再掲を置かない
- 出典は本文中の該当語句にリンクを埋め込み、最下部の出典行は補足にする
- 口語・比喩・造語・挿入倒置を使わない。用語は正式な技術用語にし、噛み砕きは添え文が担う

## 見本

型の見本は [samples/sample.js](samples/sample.js) にある。章扉、目次、節扉、箇条書き、2 列レイアウト、比較表、データから組む表、フロー図、表とコードの併置、NG と OK の対比、パターンボックスなど、代表的な型を 1 つずつ収めている。
**新しいスライドは、最も近い型を複製して書き換える。座標を発明しない。**

## 画像生成に使うとき

画像生成 MCP `slide-image-gen` を併用する場合、プロンプトは theme.json の `colors` と `imagePrompt` から組み立て、`quality` は `high` にする。
作らせるのは**スライド 1 枚の案**で、タイトル・見出し・図中のラベルを短い日本語で含める。文字を抜いた図版だけを作らせない。配置と情報の並びごと設計してもらうことが、画像生成を使う理由になる。

**生成画像はスライドに配置しない。** 図形とアイコンで再構成するか、`../image-to-pptx` で要素に分解して変換する。
再構成では画像をそのまま写さず、下部のまとめ帯を落として主張をキーメッセージへ畳み、表・本文を足して密度を確保する。画像内の文字は生成モデルが書いたものなので、上の文章規範に合わせて直す。

## このフォーマットを外す

別のブランドや書式で作る場合は、このスキルを使わない。content-to-pptx だけで、次のいずれかを使う。

| 方法 | 手順 |
|---|---|
| 参考画像から起こす | `../image-to-pptx/scripts/extract_style.py` で草案を作り、`deck-src/theme.json` に置く |
| 手で決める | `deck-src/theme.json` の色とフォントを書き換える |
| 指定しない | content-to-pptx 同梱のニュートラルテーマ（グレー基調）がそのまま使われる |
